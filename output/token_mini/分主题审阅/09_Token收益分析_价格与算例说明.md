# Token 文本收入：价格与算例说明

核查日期：2026-09-16。仅计算文本输入及输出 token 收入。

## 官方价格参考

模型：DeepSeek-V4.1-Flash（deepseek-flash）。单位：人民币元 / 百万 token。

| 类别 | 空闲时段 | 高峰时段 |
|---|---:|---:|
| 输入：缓存未命中 | 1 | 2 |
| 输入：缓存命中 | 0.02 | 0.04 |
| 输出 | 4 | 8 |

北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰，其余为空闲时段。

来源：[DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/?article_id=article_1779470751466_8)。价格可能调整，签约或测算时应重新核实。

Logo 来源：[DeepSeek 官方 GitHub 账号](https://github.com/deepseek-ai)，图片地址 https://github.com/deepseek-ai.png 。

## 公式与单位

每类月收入 = [整套服务对应吞吐量（token/分钟） ×（30天 × 24小时/天 × 60分钟/小时）× 可计费产出比例 × 对应单价数值（元/百万 token）] ÷ 1,000,000。

三类为未命中输入、命中输入、输出，分别使用对应价格，最后求和。整个乘积放入括号，以明确除数作用于全部分子。整套服务吞吐量不再乘卡数。若使用每秒吞吐量，应把时间换算为秒。

## PPT 算例（假设数据，不是实测结果）

同一业务负载下，输入 600,000 token/分钟，其中按 token 计缓存命中率 90%，即未命中 60,000、命中 540,000；输出 60,000 token/分钟。可计费产出比例均为 50%。

为了演示，全部按空闲时段单价作统一估值：

- 未命中输入：[60,000 ×（30 × 24 × 60）× 50% × 1] ÷ 1,000,000 = 1,296.00 元。
- 命中输入：[540,000 ×（30 × 24 × 60）× 50% × 0.02] ÷ 1,000,000 = 233.28 元。
- 输出：[60,000 ×（30 × 24 × 60）× 50% × 4] ÷ 1,000,000 = 5,184.00 元。
- 文本月收入参考估值：1,296.00 + 233.28 + 5,184.00 = **6,713.28 元**。

这不是按真实高峰/空闲时段分布计算的月收入预测。真实跨时段业务应按各时段的可计费 token 数分别乘价格后求和。

## 使用边界

公开 API 零售价仅作市场参考，不能直接视为项目实际成交价、实际收入或利润。上述例子也不证明现有硬件已能部署该模型或达到假设性能。

三类吞吐量须来自同一负载及一致时间窗口，不能把不同专项压测峰值相加；缓存命中 token 为可计费的逻辑复用输入量。可计费产出比例仅计入尚未被吞吐量统计覆盖的需求、可用性与计费折损，避免重复扣减。
